# HR Analytics Dashboard

An interactive **HR Analytics Dashboard** built using Microsoft Excel to analyse employee demographics, workforce composition and employee attrition.

## Project Overview

This project analyses **1,470 employee records** to identify patterns in employee attrition and workforce demographics.

The dashboard transforms raw employee data into interactive visualisations and KPI metrics to provide a clear overview of workforce trends.

## Key Metrics

- Total Employees: **1,470**
- Attrition Count: **237**
- Active Employees: **1,233**
- Attrition Rate: **16.12%**
- Average Employee Age: **36.92 years**

## Analysis

The dashboard examines employee attrition and workforce characteristics across:

- Department
- Job Role
- Age Group
- Gender
- Education
- Marital Status

## Key Features

- Interactive Excel dashboard
- KPI metrics for workforce and attrition analysis
- PivotTables and PivotCharts
- Excel formulas and calculated metrics
- Data analysis across multiple employee demographics
- Visual presentation of workforce and attrition trends

## Tools & Technologies

- Microsoft Excel

## Dataset

The dataset contains **1,470 employee records** with demographic, employment and organisational attributes.

The analysis focuses on identifying patterns in employee attrition and workforce composition.
